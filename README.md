# Lumenzzatto

Premium electrical services landing page. Static HTML/CSS/JS, no build tooling required.

## Contact form
The form prepares a plain-text budget request and copies it locally for the visitor to paste into their preferred contact channel. It does not transmit or store personal data.

## Publish with GitHub Pages
Merge to main, then in repository Settings → Pages select GitHub Actions as the publishing source. The workflow at `.github/workflows/pages.yml` deploys the root site.

Decorative code streams and energy effects are visual only, not live electrical telemetry. Validate the site on browsers and devices before public launch.
